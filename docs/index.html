Mengapa nitirekso Berbeda?

Solusi Jurnal Trading Kripto untuk Evaluasi Futures

Banyak trader berhenti mengisi jurnal trading kripto setelah seminggu karena lelah mengetik ulang data transaksi di spreadsheet. nitirekso adalah aplikasi jurnal trading otomatis yang dirancang dari sudut pandang trader aktif untuk menyelesaikan masalah ini.

⚡

Jurnal Trading Otomatis

Tarik histori posisi tertutup, harga fills rata-rata, komisi, dan funding fee langsung dari MEXC & Bitunix dalam 1 klik. Tanpa salah ketik manual.

🛡️

Jurnal Trading Offline & Privat

Portofolio dan performa keuangan Anda adalah privasi mutlak. Tersimpan di database SQLite lokal di laptop Anda tanpa dikirim ke server cloud mana pun.

🎯

Eksekusi vs Hasil (Grade A/B/C/D)

Latih kedisiplinan mental dengan memisahkan kualitas eksekusi dari sekadar PnL. Evaluasi *good loss* yang disiplin dan singkirkan *bad win* hasil keberuntungan.

📊

Analitik Mendalam & Heatmap

Pantau Equity Curve, Drawdown, Rasio Imbalan R-Multiple, dan Kalender Heatmap untuk mengetahui pola hari dan sesi paling menguntungkan.

Fitur Lengkap

Infrastruktur Lengkap untuk Trader Disiplin

Dari pencatatan emosi pre-trade hingga generator kartu pamer PnL estetik beresolusi Retina.

1. Sinkronisasi MEXC & Bitunix

Ditenagai engine CCXT terverifikasi dan REST API resmi. Engine idempotent menjamin tidak ada trade yang tercatat ganda meski sinkronisasi dijalankan berulang kali.

2. Jurnal Emosi & SOP Checklist

Catat tesis analisa sebelum open posisi dan review psikologi sesudahnya. Dilengkapi checklist kepatuhan SOP dan tagging kustom (seperti #FOMO, #Breakout).

3. Generator Kartu PnL Estetik

Bagikan pencapaian ke media sosial dengan kartu performa canvas Retina 2x dalam 5 tema visual (*Obsidian Gold, Cyberpunk Neon, Emerald Mint, Sunset, Minimal Dark*).

4. Kalkulator R-Multiple Otomatis

Ketik Stop Loss dan Take Profit rencana; nitirekso langsung menghitung Risk-to-Reward Ratio (RR) rencana dan membandingkannya dengan realisasi penutupan posisi.

5. Ekspor PDF, CSV & Google Drive

Ekspor catatan jurnal ke dokumen PDF beresolusi tinggi, format CSV siap Excel, atau sinkronkan cadangan database secara aman ke Google Drive.

6. Wawasan Pola Berbasis AI

Hubungkan kunci API AI pilihan Anda untuk menganalisis kebiasaan buruk, kebocoran modal (*capital leak*), dan saran peningkatan strategi trading secara objektif.

Pertanyaan Umum

Frequently Asked Questions (FAQ)

Semua hal yang perlu Anda ketahui mengenai keamanan, cara kerja, dan instalasi nitirekso.

Apakah menghubungkan API MEXC dan Bitunix ke nitirekso aman?
Sangat aman. nitirekso hanya meminta izin Read-Only (hanya baca) untuk menarik riwayat posisi tertutup dan saldo akun. Aplikasi ini tidak memiliki kapabilitas untuk membuat order, mengubah posisi, apalagi melakukan penarikan dana (withdraw). Kunci API Anda dienkripsi langsung di mesin lokal menggunakan Windows DPAPI (safeStorage).
Mengapa menggunakan aplikasi otomatis lebih baik daripada spreadsheet Excel?
Spreadsheet manual menuntut trader mengetik ulang harga entry, exit, fee, dan funding satu per satu. Ini melelahkan dan rawan salah ketik (human error). nitirekso menarik data resmi exchange secara instan dalam hitungan detik, menghitung Risk to Reward (RR) secara otomatis, dan memvisualisasikan kalender heatmap tanpa perlu rumus rumit.
Apakah ada biaya langganan bulanan tersembunyi?
Tidak ada sama sekali. nitirekso adalah aplikasi open-source di bawah lisensi MIT. Anda mengunduh installer mandiri (.exe) dan bebas menggunakannya tanpa batasan kuota transaksi atau masa percobaan.
Apa itu pemisahan Execution Grade (A/B/C/D) vs Hasil PnL?
Hasil profit bisa saja didapat dari melanggar rencana trading (bad win), dan kerugian bisa saja terjadi saat aturan telah dijalankan dengan disiplin (good loss). nitirekso melatih Anda mengevaluasi kepatuhan proses eksekusi, bukan sekadar nominal uang, demi membentuk psikologi trading yang tahan banting.
Bagaimana cara menginstal nitirekso di komputer Windows saya?
Cukup kunjungi halaman GitHub Releases, unduh file nitirekso-Setup-1.0.0.exe, dan klik dua kali untuk memasang. Aplikasi siap digunakan secara instan tanpa perlu instalasi database atau software tambahan.
