ꦤꦶꦠꦶ

Niti

Menulis, mencatat, dan meneliti secara saksama. Setiap eksekusi direkam apa adanya langsung dari data bursa tanpa polesan emosi.

ꦫꦼꦏ꧀ꦱ

Rekso

Menjaga modal (capital preservation) dan merawat ketenangan disiplin agar akun tetap bertahan dalam berbagai fase pasar.

Dua garis candlestick emas dan teal pada lambang nitirekso merujuk pada keseimbangan antara ketelitian pencatatan (Niti) dan ketahanan menjaga risiko (Rekso).

01

Pencatatan Terpadu tanpa Duplikasi

Banyak trader berhenti menulis jurnal karena lelah menyalin harga entry, exit, biaya komisi, dan funding fee secara manual di spreadsheet. Pipeline Two-Phase Exchange Sync menarik data lima bursa dalam satu alur idempoten sehingga transaksi tercatat konsisten tanpa entri ganda.

02

SQLite Lokal dengan Enkripsi Kredensial Native

Seluruh riwayat trading, lampiran gambar chart, dan catatan pribadi tersimpan di database SQLite WAL pada perangkat Anda sendiri, bebas dari server perantara atau pelacak telemetri. Kunci API dilindungi oleh enkripsi native Rust AES-256-GCM bersama keychain sistem operasi.

03

Memisahkan Kualitas Eksekusi dari Nominal PnL

Profit sesekali akibat melanggar stop loss (bad win) sering menutupi kelemahan disiplin, sementara rugi yang mengikuti aturan risiko (good loss) tetap sehat dalam jangka panjang. Execution Grade (A/B/C/D) menguji kepatuhan Anda terhadap SOP sebelum angka dolar berbicara.

Arsitektur & Kapabilitas

Dibangun sebagai Instrumen Desktop Native dengan Tauri v2 dan Rust.

nitirekso berjalan menggunakan WebView bawaan sistem operasi dan backend terkompilasi Rust tanpa mengemas browser Chromium atau runtime Node.js di dalam paket rilisnya.

Fondasi Sistem

Konsumsi Memori Ringkas dan Jembatan IPC Biner

Komunikasi frontend dan backend memakai TypedIpcClient dengan kontrak respons tunggal AppResult serta aliran biner langsung (Uint8Array / Vec<u8>) untuk rendering media video tanpa overhead pengkodean JSON base64.

01

Trading Analytics & Performance Report Engine

Kalkulasi satu lintasan berkecepatan single-pass untuk Net PnL, Win Rate, Profit Factor, Expectancy (dalam R), Max Drawdown, Recovery Factor, Max Streak, serta Sharpe dan Sortino Ratio di atas kurva ekuitas yang telah disanitasi.

02

Benchmark Alpha VS ROI Bitcoin

Bandingkan persentase return strategi aktif Anda langsung dengan kinerja Buy & Hold Bitcoin pada jendela waktu identik, ditopang 4-tier failover data kline agar grafik perbandingan tetap utuh.

03

Card Media Engine (9:16, MP4 FastStart & GIF)

Rendering kanvas mandiri untuk rasio 16:9, 4:5 Feed, dan 9:16 vertikal lengkap dengan audio muxing, penataan atom moov di awal berkas MP4, ekspor GIF animasi offline, serta Mode Sensor Privasi (Hide P&L).

04

Jurnal Tesis, Rencana RRR & Audit AI Opsional

Dukung penulisan tesis pre-trade, tag emosi, checklist SOP, perhitungan Risk-to-Reward terencana, lampiran screenshot lokal, serta koneksi opsional OpenAI Chat Completions menggunakan API key pribadi Anda.

05

Two-Phase Sync & Concurrency Hardening

Pemisahan fase pengambilan data HTTP dari fase penulisan SQLite memastikan antarmuka tidak pernah membeku oleh database lock ketika mengunduh riwayat dari banyak bursa secara bersamaan.

06

Restore Backup SQLite Online API & Ekspor Data

Pulihkan database dan koleksi screenshot satu klik memakai rusqlite::backup::Backup lengkap dengan auto-migrasi skema, atau ekspor catatan ke CSV (UTF-8 BOM), JSON, PDF, dan Google Drive.

Buka Diskusi & Issues di GitHub
Apakah menghubungkan API Bybit, Binance, BingX, MEXC, dan Bitunix ke nitirekso aman?

Aman. nitirekso hanya meminta izin Read-Only (hanya baca) untuk membaca posisi tertutup, fills, biaya transaksi, dan saldo futures. Kode aplikasi tidak memuat endpoint untuk menaruh order maupun melakukan penarikan dana (withdraw). API Key dan Secret dienkripsi di komputer Anda menggunakan pustaka Rust AES-256-GCM serta keychain bawaan sistem operasi.

Apa kelebihan Two-Phase Unified Sync dibanding menyalin histori ke spreadsheet?

Selain menghemat waktu dari input manual yang rawan salah ketik, Two-Phase Exchange Sync memisahkan tahap pengunduhan HTTP dari penulisan ke database SQLite WAL. UI tetap responsif selama sinkronisasi berlangsung dan setiap riwayat dijamin idempoten sehingga tidak ada trade ganda saat sinkronisasi ulang.

Apakah nitirekso benar-benar gratis tanpa batas kuota transaksi?

Ya. nitirekso adalah proyek desktop open-source di bawah lisensi MIT. Tidak ada sistem berlangganan bulanan, tidak ada kunci lisensi berbayar, dan tidak ada pembatasan jumlah posisi trading yang disimpan di database lokal Anda.

Mengapa Execution Grade (A/B/C/D) dipisahkan dari hasil nominal PnL?

Dalam futures, posisi yang melanggar aturan risiko tetap bisa kebetulan menghasilkan profit (bad win), sementara posisi yang sepenuhnya mematuhi SOP tetap bisa menyentuh stop loss (good loss). Menilai eksekusi secara terpisah membantu Anda menjaga kebiasaan trading yang sehat dalam jangka panjang.

Apakah data histori trading dikirim ke server luar, termasuk saat memakai fitur AI?

Basis data nitirekso 100% tersimpan secara lokal di SQLite tanpa server pengumpul data atau telemetri. Fitur wawasan AI bersifat opsional dan baru berkomunikasi dengan endpoint OpenAI Chat Completions apabila Anda secara eksplisit memasukkan API key pribadi dan meminta analisis transaksi.

Bagaimana cara kerja ekspor video 9:16 dan fitur Restore Backup?

Card Media Engine merender kartu performa langsung ke kanvas beresolusi tinggi lalu mengekspornya sebagai PNG, GIF animasi offline, atau video MP4 H.264 dengan faststart remuxing agar durasi tidak terpotong di TikTok maupun Reels. Untuk cadangan, fitur Restore Backup memakai SQLite Online Backup API guna memulihkan database sekaligus screenshot lokal dalam satu klik.

Format installer apa saja yang tersedia untuk Windows, macOS, dan Linux?

Anda dapat mengunduh rilis resmi untuk Windows 10/11 64-bit dalam format NSIS Setup (.exe) dan .msi, paket .dmg macOS untuk chip Apple Silicon maupun Intel, serta .AppImage dan paket .deb untuk berbagai distro Linux.

Pusat Unduhan Multi-Platform

Unduh nitirekso Desktop dari Rilis Resmi GitHub.

Seluruh tautan mengarah langsung ke halaman rilis terbaru resmi repositori nitirekso. Pilih sistem operasi perangkat Anda di bawah ini.

Kompatibel dengan Windows 10 dan Windows 11 (64-bit) menggunakan WebView2 bawaan Windows tanpa instalasi runtime terpisah.

Windows Setup (NSIS)

.EXE

Installer interaktif standar dengan dukungan pembaruan terintegrasi untuk pengguna Windows desktop.

Unduh Installer Windows (.exe)

Windows Installer Package

.MSI

Paket pemasangan standar Windows Installer untuk instalasi tingkat mesin (per-machine) yang rapi dan mudah dikelola.

Unduh Paket Windows (.msi)

Catatan Windows: Installer terkonfigurasi dalam mode perMachine; ikuti prompt standar Windows bila diminta. Seluruh data jurnal SQLite dan cadangan lokal tersimpan di direktori data aplikasi pengguna (%APPDATA%).

Mendukung macOS modern dengan binary native terpisah untuk arsitektur Apple Silicon maupun prosesor Intel x64.

macOS Apple Silicon (M-Series)

.DMG (arm64)

Build native ARM64 untuk Mac dengan chip M1, M2, M3, dan M4 memanfaatkan WebKit bawaan macOS.

Unduh DMG Apple Silicon

macOS Intel (64-bit)

.DMG (x64)

Paket disk image native khusus perangkat Mac berbasis prosesor Intel x86_64.

Unduh DMG Intel x64

Catatan macOS: Buka berkas .dmg lalu seret ikon nitirekso ke folder Applications. Saat pertama kali dijalankan, jika muncul peringatan pengembang tidak dikenal di Gatekeeper, klik kanan aplikasi lalu pilih Open.

Tersedia untuk distribusi desktop utama termasuk Ubuntu, Debian, Linux Mint, Fedora, dan Arch Linux (x64).

Linux AppImage Portabel

.AppImage (x64)

Berkas mandiri lintas distro yang dapat dijalankan langsung tanpa proses instalasi paket sistem.

Unduh Linux AppImage

Paket Debian / Ubuntu

.DEB (x64)

Paket instalasi sistem terintegrasi ke menu aplikasi desktop bagi turunan Debian dan Ubuntu.

Unduh Paket DEB

Catatan Linux: Untuk menjalankan berkas AppImage via terminal, berikan izin eksekusi terlebih dahulu dengan perintah chmod +x nitirekso*.AppImage && ./nitirekso*.AppImage.
